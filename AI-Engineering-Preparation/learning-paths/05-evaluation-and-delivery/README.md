# Path 05: Evaluation & delivery

How to know whether an LLM system works, and how to ship changes without regressions. This path covers offline and online evaluation, LLM-as-judge, regression gates and guardrails, and the AI-assisted build loop — ending in system-design capstones.

## Learning objectives

- Design offline evaluations with golden sets and appropriate metrics.
- Use LLM-as-judge responsibly and calibrate it against human labels.
- Gate regressions in CI and add runtime guardrails.
- Run a spec-to-verify build loop and reason through a system-design capstone.

## Planned modules

1. Why evaluation is the bottleneck: offline vs. online.
2. Metrics and golden sets.
3. LLM-as-judge: uses, biases, and calibration.
4. Regression gates and guardrails.
5. The AI-assisted coding workflow: spec, plan, implement, verify.
6. System-design capstones: putting it together.
