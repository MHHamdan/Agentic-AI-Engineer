# Path 04: Agents, patterns & protocols

What separates an agent from a single model call: a loop that reasons, calls tools, observes results, and repeats. This path covers the agent loop, the design patterns that make agents reliable, the protocol for connecting them to tools, and how multiple agents coordinate.

## Learning objectives

- Implement the reason-act-observe loop with tool calls.
- Apply agentic patterns (reflection, planning, tool use, and others) and say where each breaks.
- Explain the Model Context Protocol: clients, servers, tools, and resources.
- Compare multi-agent coordination architectures and pick one before writing code.

## Planned modules

1. The agent loop: reason, act, observe.
2. Tool use and tool schemas.
3. Agentic patterns: reflection, planning, tool use, and more.
4. The Model Context Protocol: client/server, tools, resources.
5. Multi-agent coordination: supervisor, network, hierarchical.
6. Handoffs and inter-agent protocols.
