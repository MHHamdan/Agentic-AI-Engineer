# Learning paths

Five ordered paths take you from model foundations to evaluation and delivery. Each path is a sequence of concept notes, labs, and a capstone; the table below is the intended order. Content arrives batch by batch — see the track [CHANGELOG](../CHANGELOG.md).

| # | Path | You will be able to |
|---|---|---|
| 01 | [LLM foundations](./01-llm-foundations/) | Explain how a model turns text into tokens and predictions, and choose between fine-tuning and retrieval. |
| 02 | [ML & RL fundamentals](./02-ml-and-rl-fundamentals/) | Reason about the ML lifecycle and serving, and explain how RL and RLHF shape model behavior. |
| 03 | [Retrieval & memory](./03-retrieval-and-memory/) | Build a RAG pipeline, pick a vector index, and separate agent state from memory. |
| 04 | [Agents, patterns & protocols](./04-agents-patterns-protocols/) | Implement an agent loop with tools, apply agentic patterns, use MCP, and coordinate multiple agents. |
| 05 | [Evaluation & delivery](./05-evaluation-and-delivery/) | Evaluate LLM systems offline and online, gate regressions, and run an AI-assisted build loop. |

Concept notes live under [`../concepts/`](../concepts/); hands-on work under [`../labs/`](../labs/); capstones under [`../projects/`](../projects/).
