# Project: Personal AI chat assistant

Design and build a personal chat assistant end-to-end: a model behind a conversation loop, grounded by retrieval, with memory across sessions and an evaluation harness to keep it honest.

> Batch 00: specification. The build arrives in a later batch.

## Objectives

- Design the request flow from user turn to grounded answer.
- Add retrieval over a personal corpus and citations.
- Add session memory and a context budget.
- Evaluate quality offline and watch it online.

## Planned deliverables

- A system-design write-up with a diagram.
- A runnable assistant skeleton with retrieval and memory.
- An evaluation harness with a small golden set.
