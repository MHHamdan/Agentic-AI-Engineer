# Project: RAG with evaluation

Build a retrieval-augmented system over a corpus and, just as important, the evaluation that tells you whether it is any good: retrieval quality, grounding, and citation, scored separately.

> Batch 00: specification. The build arrives in a later batch.

## Objectives

- Build chunk-embed-retrieve-rerank-generate over a corpus.
- Add citations and check that sentences are supported.
- Score retrieval, coverage, and citation as separate axes.
- Gate changes on the evaluation.

## Planned deliverables

- A runnable RAG pipeline.
- An evaluation harness covering coverage and citation.
- A short report reading the results.
