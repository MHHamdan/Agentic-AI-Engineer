# Project: ML system design exercise

Work a classic ML system-design problem from requirements to a served prediction: data and features, training, serving, and the monitoring that keeps it from silently degrading.

> Batch 00: specification. The build arrives in a later batch.

## Objectives

- Translate a vague requirement into a measurable ML problem.
- Design the feature, training, and serving paths.
- Specify monitoring for drift and skew.
- Reason about scale, latency, and cost tradeoffs.

## Planned deliverables

- A requirements-to-architecture write-up.
- A component diagram of the data and serving paths.
- A monitoring and retraining plan.
