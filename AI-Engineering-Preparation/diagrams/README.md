# Diagrams

Reusable diagram sources, authored in [Mermaid](https://mermaid.js.org/) so they render on the repository host and stay diffable in version control.

> Batch 00: stub. Diagrams arrive with the content batches.

## Conventions

- One concept per diagram; keep it readable at a glance.
- Prefer `flowchart` for pipelines and `sequenceDiagram` for protocols.
- Store a diagram here when it is shared across notes; inline small one-off diagrams in the note that uses them.
